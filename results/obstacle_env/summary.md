# Phase 3 — 관측 가능한 장애물 gym: 구축과 검증

목적(2026-07-16 합의): 웨이포인트가 만들던 **인위적 다봉 사다리(~14 step)** 없는
환경 재구성. 비효율의 원천을 "관측 불가능한 웨이포인트"에서 "관측 가능한 장애물
우회 + 액션 노이즈"로 교체.

## 환경/데이터 설계 (src/obstacle_env.py)

- `ObstacleAvoidPoint2D(EnhancedPoint2D)`: 시작/골 랜덤(최소거리 0.6), 경로상
  장애물 1개(선분 30~70% + 수직 지터, 반경 U(0.1,0.25), 벽 통로 ≥0.25 보장),
  관측 5필드 9차원(cur_pos, cur_vel, goal_pos, obstacle_rel_pos, obstacle_radius),
  맵 경계 [-1,1]² 물리 벽(장애물과 동일 의미론).
- 데모 컨트롤러: PD + 포텐셜필드(선형 램프 반발+접선) + **백색 노이즈 1.5e-4**
  (사용자 선택). 성공률 99%, 길이 p50=94 p99≈430. 접선점 조준 컨트롤러
  (`avoid_controller`)도 비교용으로 유지.
- 시행착오 기록: 1/d 반발(교착) → 선형 램프(회전방향 뒤집힘 진동) → 접선점
  조준(8/8 성공, 너무 매끈) → PF+노이즈 2e-4(성공 99%, 너무 구불) → **1.5e-4 채택**.
  노이즈는 데이터 수집 전용, 추론 시 미주입.

## 학습 (src/train_obstacle_predictor.py)

- 데모 10,000 에피소드 = 1,186,058 transitions (`data/obstacle_demos.pkl`).
- bin_size=1, num_bins=500(=에피소드 상한 → 라벨이 범위를 구조적으로 못 넘음).
- MLP 256×3, Adam 3e-4, 32,768 step (train_sft와 동일 하이퍼).
- 결과: **BC 정책 성공률 0.96** (구맵 0.84보다 높음), val MAE=50.4, NLL=5.10.
  MAE 50은 예측기 결함이 아니라 노이즈 데모의 **aleatoric floor** — 4,096 step에
  이미 도달 후 그대로 (같은 상태에서도 미래가 원리적으로 불확실).
- 체크포인트: `checkpoints/obstacle/predictor.pkl` (obs_fields 자기술 포함,
  `src/probe_generic.GenericSTGProbe`로 로드).

## 핵심 검증: 인위적 사다리가 사라졌나 (src/diagnose_obstacle_multimodal.py)

나이브한 다봉 비율은 오히려 증가(0.72→0.82)해 보이지만, 이는 **가짜 신호** —
두 판별 기준이 정반대 성격을 보여준다 (`ladder_comparison.png`):

| 판별 기준 | 구맵(웨이포인트) | 신맵(장애물+노이즈) |
|---|---|---|
| 간격의 임계값 불변성 | 15~16 고정 (prom 0.1/0.2/0.3) | 9→16→25 표류 (특징 주기 없음) |
| 간격 히스토그램 | 14~18 집중 + ~32 고조파 | 매끄러운 감쇠, 구조 없음 |
| **평활화 내성** (이동평균 w=1/3/5/9) | 다봉비율 0.72/0.73/0.72/0.62, 간격 16 고정 | **0.83/0.66/0.46/0.19 붕괴**, 간격 16→89 표류 |

**결론: 인위적 다봉 사다리는 제거 성공.** 구맵의 다봉성은 평활화에도 살아남는
고정 주기(16 step) 구조(=웨이포인트 사다리)인 반면, 신맵에서 피크 검출에 잡히는
것은 500-way 카테고리 헤드의 **bin 단위 잔물결**(인접 bin 간 평활성 제약이 없는
구조적 노이즈)일 뿐, 살짝만 평활화해도 사라진다. 실제 분포 모양은 "넓고 매끄러운
언덕"(스냅샷 패널) — 의도한 연속적·정직한 불확실성.

## 후속 분석 시 주의

- 피크 기반 분석은 w=3~5 이동평균 후 수행할 것 (bin 잔물결 제거).
- σ²(적분 기반)은 잔물결에 둔감하므로 그대로 사용 가능.
- RL(Stage 2) 후 분포가 얼마나 좁아지는지가 다음 자연스러운 측정 — 지금 결과가
  그 베이스라인.
